# Delivery notes

## Next build

Run the final candidate through a genuinely independent, brand-new-context red
team using an allowlisted packet and a recorded isolation manifest, reconcile the
verified challenges, and package a hash-complete delivery manifest. Add retained
RSS sampling to complement the current Python-allocation scale measurement.

## Surprises

The first shadow report passed mechanical validation while mapping transaction
answers to the wrong headings, reversing variance wording and retaining stale
vision limitations. A distinct semantic fixture and human review caught defects
that primary-room golden tests did not.

## Least-confidence areas

Issue recall on highly unstructured or image-heavy confidential rooms remains
less certain than registration, extraction and citation integrity. Optional OCR
was absent in the acceptance environment. Irish contract and tax outputs remain
commercial diligence, not formal opinions. Final red-team independence has not
yet been proved.

## Bigger-budget changes

With a larger budget, use an actually exposed economical model for bulk
classification and a separately verifiable frontier context for red team; retain
actual provider token/cost telemetry only where the harness exposes it. Add more
diverse sealed rooms, independent legal/tax specialist review, multi-OS/offline
clone benchmarks, fuzzed document parsers and process-RSS/long-duration tests.
None of those upgrades justifies inventing a model call, token count or cost in
the current local ledger.
